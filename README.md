### What I Do

**Cloud Architecture & Large-Scale Migrations**
Led 8+ complex migration programs — on-prem to cloud, cross-cloud (AWS → GCP, Azure → GCP), and legacy re-platform initiatives. Zero downtime is a design constraint, not an afterthought.

**Platform Engineering & SRE**
Built internal developer platforms on Kubernetes that scaled to 4.5M req/sec. Focus on golden paths, self-service infrastructure, and reducing cognitive overhead for 100+ application teams.

**AI & Intelligent Systems**
Exploring self-hosted LLMs, RAG pipelines, and on-device AI as production infrastructure primitives. Running experiments in the homelab — notes at [amit.cloud/lab](https://amit.cloud/lab).
